## ABOUT

Galaxy Studio is a luxury product landing page built as a technical showcase for scroll-driven animation architecture. Designed around the Galaxy Pistachio Kunafa Limited Edition product, the site demonstrates production-grade animation engineering — combining React 18, Framer Motion physics, Canvas 2D optimization, and requestAnimationFrame syncing to deliver buttery-smooth visual experiences at 60fps.

Built to meet the performance and aesthetic standards of Dubai and Abu Dhabi's hyper-competitive digital market, with RTL-ready architecture for seamless Arabic localization.

---

## HOW IT WORKS

```
Scroll Position  →  requestAnimationFrame Loop
                          ↓
             Framer Motion Physics Engine
                          ↓
        Canvas 2D Context  +  Sub-pixel Anti-aliasing
                          ↓
         Synchronized Scroll-driven Visual Journey
```

---

## TECHNICAL ARCHITECTURE

| Principle | Implementation |
|---|---|
| React 18 Architecture | Concurrent rendering, state-driven animation triggers |
| Framer Motion Physics | Spring-based scroll animations, viewport-synced transitions |
| Canvas 2D Optimization | Hardware-accelerated rendering for particle and image effects |
| requestAnimationFrame Syncing | DOM reads and writes batched to eliminate layout thrashing |
| Sub-pixel Anti-aliasing | Pixel-perfect rendering across all display densities |
| Zero Layout Thrashing | Isolated DOM reads, batched writes via RAF loops |
| Pre-loaded Asset Pipeline | Immediate time-to-interactive on all network conditions |
